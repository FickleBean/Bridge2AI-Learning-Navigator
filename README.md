# Bridge2AI-Learning-Navigator
Interactive learning platform for Bridge2AI Training.

This repository hosts the interactive **Bridge2AI Learning Navigator** web application. 

## Overview
The Learning Navigator is a self-contained learning platform designed to support training modules across the Bridge2AI ecosystem. It is built as a static HTML application and deployed automatically via GitHub Pages.
